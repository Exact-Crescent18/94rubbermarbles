Connect to the repo

This page saves changes by committing directly to the 94rubbermarbles GitHub repo on your behalf. It needs a personal access token — a password-like key you create once — to be allowed to do that.

  1. Go to github.com/settings/tokens and create a new fine-grained token.
  2. Under "Repository access", choose Only select repositories and pick 94rubbermarbles.
  3. Under "Permissions", set Contents to Read and write.
  4. Generate it, copy the token, and paste it below. It's stored only in this browser (localStorage) — never sent anywhere except directly to GitHub's API.
